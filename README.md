# Vue 3 前端互動練習

此 Repository 保存以 Vue 3 製作的簡易計算機練習，包含兩份相近的 HTML 實作，示範 Vue 的資料綁定、事件處理、條件判斷與列表渲染。

這是前端學習練習，不是完整計算機產品。

## 技術

- HTML / JavaScript
- Vue 3
- Bootstrap 5
- Vue `v-model`、`v-for`、`@click`、`:class`

## 功能概念

- 輸入兩個數字並選擇加、減、乘、除。
- 按下按鈕後計算結果。
- 將運算式與結果加入歷史紀錄。
- `calculator.html` 另有清除紀錄按鈕，但目前實作只移除最後一筆紀錄。

## 已知限制

- 尚未處理除數為零、空值與非有限數值等輸入情境。
- `clearHistory` 使用 `pop()`，只會移除最後一筆，不是清空全部紀錄。
- 預設運算子初始值為 `add`，與 switch case 使用的符號不一致；首次計算前需先選擇運算子才會進入對應分支。
- 兩份 HTML 的程式結構相近，屬於練習版本，不代表兩個獨立作品。

本 Repository 主要佐證 Vue 3 基礎互動與資料驅動畫面練習。
